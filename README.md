# AVS03 Mods

[GDPatch](https://gdpatch.dev/) mods for [Antivirus Survivors 2003 Professional](https://store.steampowered.com/app/3832490/Antivirus_Survivors_2003_Professional/).

## Install

1. Install [GDPatch](https://gdpatch.dev/using/install/)
2. Download the entire repo [here](https://github.com/letruxux/avs03-mods/archive/refs/heads/main.zip)
3. Extract the mod you want from the .zip to `{GAME_FOLDER}/GDPatch/mods`

## Mods

### No Achievements

Disables all achievements (and stats). Configure at `GDPatch/configs/no_achievements.toml`

### ThemeLib

Adds custom wallpapers and themes (WIP) to the game.

#### How to add wallpapers

1. Go at `GDPatch/mods/themelib/data/assets/custom_wallpapers`
2. Add `.png` files there. (they must be .png!), they will be resized and/or stretched to fit the original wallpaper resolution.

### Content+ (WIP)

Adds more enemies / clickables / weapons (or atleast thats the plan)

#### New stuff

- **MountainVPN clickable**: Gives you 1.5x speed buff and a 100% dodge buff for 5 seconds to flee from huge enemy waves
